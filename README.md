
# 👋 Hey, I'm João Victor!

# 🧠 DataViva AI

> **Internal DataViva project — currently under development**

As part of my work at DataViva, I'm also developing an experimental AI system focused specifically on the platform's data ecosystem.

The goal is not simply to build a generic chatbot, but to create a specialized **AI harness for interacting with and understanding Cedeplar / DataViva datasets**.

The project explores a workflow where an LLM can combine:

- Retrieval over documentation and dataset metadata
- Data-oriented tools
- Structured access to datasets
- Context about data sources and methodology
- Natural-language explanations
- Evaluation and benchmarking

The idea is to allow users to ask questions about the available datasets in natural language while maintaining explicit context about **where the information came from, what the dataset represents and how the answer was produced**.

The project is being developed as an internal DataViva initiative and will receive its own repository / documentation once it reaches a stable stage.

**Focus:**  
`RAG` · `LLM Applications` · `Data Retrieval` · `Tool Use` · `Evaluation` · `Data Understanding`

> 🚧 **Currently in development**
