# 🚀 Featured Projects

### 🔎 DataViva AI

An experimental AI interface for exploring and understanding the datasets available in the **Cedeplar / DataViva ecosystem**.

The project explores a specialized AI harness combining retrieval, data-oriented tools and structured evaluation to allow users to ask questions about datasets in natural language while keeping the underlying sources and context explicit.

**Focus:** RAG · AI Agents · Data Retrieval · Evaluation · LLM Applications

---

### 🚗 Ctrl Fleet

Web application for fleet management aimed at public-sector organizations.

The project was selected as the **best project of the semester** and is currently in production.

**Stack:** `Java` · `Spring Boot` · `PostgreSQL` · `React` · `Docker`

---

### 📊 DataViva

Contributing to the modernization of a public platform for economic and geographic data.

My work includes ETL pipelines for economic-complexity indicators using Spark, Sedona and Airflow, as well as backend/web development and AWS infrastructure.

**Stack:** `PySpark` · `Spark` · `Sedona` · `Airflow` · `FastAPI` · `React` · `TypeScript` · `MongoDB` · `AWS`

---

### 🏫 School Management SaaS

A multitenant SaaS developed for a **real client**, focused on enrollment and financial management for small educational institutions.

The project involves domain modeling, business rules, tenant isolation and production-oriented development.

**Stack:** `Java` · `Spring Boot` · `PostgreSQL` · `React` · `Docker`

---

### 🔎 Obra Prima

Platform for exploring and visualizing public data related to government construction projects.

The project started as a frontend application and was later refactored into a more complete architecture using TypeScript, Node.js, MongoDB and Docker.

🌐 https://projeto-obra-prima.onrender.com
